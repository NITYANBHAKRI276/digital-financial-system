# Digital Financial System

A Java-based digital financial monitoring system
with Machine Learning-powered fraud detection,
anomaly detection, and financial risk scoring.

## Technology Stack

- Java
- Spring Boot
- PostgreSQL / Supabase
- Python
- Scikit-learn
- FastAPI
- Docker
- JavaScript / React

## Project Structure

- backend: Java Spring Boot application
- ml-service: ML model training and prediction
- frontend: User interface and dashboard
- database: Database documentation and SQL scripts
- docs: Project documentation and architecture

## Core Features

- Digital transaction processing
- Fraud detection using Machine Learning
- Anomaly detection
- Fraud risk scoring
- Suspicious transaction alerts
- Financial monitoring dashboard

## Team Collaboration

All contributors should work on separate feature
branches and submit Pull Requests before merging
changes into the main branch.
